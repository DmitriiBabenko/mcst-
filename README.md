В данном проекте реализована модель работы с набором регистров с плавающей точкой
(формата float32), которая эмулирует последовательность арифметических операций
над ними с помощью SMT-солвера Z3.

Этапы работы алгоритма:
_____

1. Формирование графа зависимостей согласно нижеприведённой модели.

2. Формирование системы ограничений Z3 в соответствии с построенным графом.

3. Разрешение системы ограничений Z3.

4. построение топологического порядка $\sigma$: V $\rightarrow$ {1, ..., |V|}, согласованный с E: $\forall$ ($v_i$, $v_j$) $\in$ E : $\sigma$($v_i$) < $\sigma$($v_j$)

5. отображение вершин на регистры:     $\rho$: V $\rightarrow$ {0, ..., regs - 1}

6. Выполнение последовательности инструкций на регистрах.

Модель графа зависимостей:

## Model

### Определения

- $G = (V, E)$ - ациклический граф, где $E \subset V \times V$.
- $deg^-(v)$ - кортеж входящих в вершину рёбер.
- $|deg^-(v)| = 0 \Leftrightarrow v$ - корень.
- $deg^+(v)$ - множество исходящих из вершины рёбер.
- $|deg^+(v)| \geq 0$ без ограничений; $|deg^+| = 0$ означает, что результат $v$ - "лист" графа.

### Модель

- Вершины $v \in V$ - результат арифметической операции, который может быть использован в других арифметических операциях.
- Корни графа соответствуют инициализации.
- На множестве вершин определена функция f: V $\rightarrow$ \{func\}.
- Рёбра $e = (v_i, v_j)$, $i \neq j$, $e \in E$ - $v_i$ является операндом при вычислении $v_j$.

### Ограничения

- $\forall v \in V$ $|deg^-(v)|$ соответствует арности одной из заранее известных арифметических операций.
- $r$ - количество корней. $2 \leq r \leq \min(size, regs)$, где $size$ - количество арифметических операций, $regs$ - количество регистров.

### $\{func\}$ | перечень арифметических операций

- SUM: $float \times float \rightarrow float$.
- SUB: $float \times float \rightarrow float$.
- MUL: $float \times float \rightarrow float$.
- DIV: $float \times (float \setminus 0) \rightarrow float$.
- INIT: $float$

Особенности реализации:
________________________
- Регистры представлены переменными типа плавающей точки в формате IEEE-754 в z3 контексте
- Применяется параметр random_seed для детерминированности псевдослучайных операций (из-за особенности работы гпсч результаты вызовов с одинаковыми параметрами будут идентичны)
- Возможность кешировать разрешённую систему ограничений по заранее известному пути.
- Возможность начинать\заканчивать программу на любых этапах(1-6).
