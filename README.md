В данном проекте реализована модель работы с набором регистров с плавающей точкой (формата float32), которая эмулирует последовательность арифметических операций над ними с помощью SMT-солвера Z3.
Цель:  
_____  
1. Сформировать (псевдо)случайную последовательность инструкций длины l в 
нижеприведённой СК, при вычислении которой:  
* все значения регистров-операндов (src) определены;  
* все промежуточные результаты являются нормализованными вещественными  
числами одинарной точности.  
2. Вывести значения всех регистров с определёнными значениями на момент 
завершения вычислений.  

Система команд:  

set <value>, <dst> // поместить значение <value> в регистр <dst>  
fmul <src1>, <src2>, <dst> // умножить значение из регистра <src1> на 
значение из регистра <src2> и поместить результат в регистр <dst>  
fadd <src1>, <src2>, <dst> // сложить -//-  
fsub <src1>, <src2>, <dst> // вычесть -//-  
fdiv <src1>, <src2>, <dst> // разделить -//-  

N регистров: %r0..%r<N-1>  

Особенности реализации:  
________________________  
* Регистры представлены переменными типа плавающей точки в формате IEEE-754 в z3 контексте  
* для каждой итерации генерируется (псевдо)случайный код одной из команд, представленных в СК  
* Операция применяется к 3 регистрам сгенерированным также (псевдо) случайным способом  
* Для каждый итерации используется отдельный z3::solver  
* Применяется параметр random_seed для детерминированности псевдослучайных операций.(из-за особенности работы гпсч результаты вызовов с одинаковыми параметрами будут идентичны)
